# Plan de versionado individual

Segun la indicacion del tutor, este trabajo se desarrolla en una rama propia y con 10 versiones sucesivas del codigo.

## Rama de trabajo

- Una rama personal por estudiante.
- Cada version debe quedar registrada de forma incremental.

## Propuesta de versiones

1. Estructura inicial del proyecto.
2. Clase base y validaciones generales.
3. Clase Cliente.
4. Clase Servicio abstracta.
5. Servicios especializados.
6. Clase Reserva.
7. Manejo de excepciones y logs.
8. Simulacion de operaciones validas e invalidas.
9. Ajustes de trazabilidad y mensajes.
10. Version final integrada y revisada.

## Recomendacion

- Mantener cada version con cambios pequenos y verificables.
- Registrar el avance en Git de forma ordenada para que se vea la evolucion real del codigo.
